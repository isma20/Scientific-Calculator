# Scientific Calculator

A desktop scientific calculator with a graphical interface, built in Python using Tkinter. It handles everyday arithmetic and a wide range of advanced mathematical functions, and lets you switch between degrees and radians for trigonometry.

![Scientific Calculator](screenshots/calculator.png)

## Features
- **Basic operations:** addition, subtraction, multiplication, division, decimal numbers and +/- sign change
- **Trigonometry:** sin, cos, tan and their inverses (sin⁻¹, cos⁻¹, tan⁻¹)
- **Angle modes:** switch between Deg and Rad
- **Logarithms and exponentials:** log, ln, exp
- **Powers and roots:** x², x³, x^y, square root
- **Other functions:** factorial (n!), absolute value, π
- **Brackets:** build longer expressions with ( and )
- **Answer recall:** reuse the previous result with `ans`
- **Memory:** M+, MR and MC buttons
- **Clearing:** C removes the last entry and AC clears everything

## Tech stack
- Python 3
- Tkinter (GUI)

## How to run
```bash
git clone https://github.com/isma20/Scientific-Calculator.git
cd Scientific-Calculator
python calculator.py
```
Tkinter comes with most Python installations, so no extra packages are needed. If your main file has a different name, use that name in the last command.
